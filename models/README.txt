Placez ici votre fichier .glb (ex: car.glb).

Source recommandée : Kenney Car Kit (CC0, aucune attribution requise)
https://kenney.nl/assets/car-kit
-> Télécharger le zip -> dossier des modèles glTF -> choisir un modèle
   type "hatchback" (le plus proche d'une silhouette de Clio)
-> Renommer le fichier "car.glb" et le placer dans ce dossier
   (build/models/car.glb)

Si vous utilisez un autre nom de fichier ou un autre chemin, changez la
valeur de MODEL_URL en haut de build/js/car3d.js en conséquence.
